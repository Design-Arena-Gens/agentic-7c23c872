# AuraShoot – AI Catalogue Apparel Shoot Platform

AuraShoot is a marketing site for an AI-powered apparel production platform. Plan virtual photoshoots, generate couture-ready prompts, and export ecommerce-ready catalogue assets without traditional studio overhead.

## ✨ Highlights

- Immersive hero with animated stat block and dual call-to-action.
- Interactive prompt builder that outputs natural language directives for generative models.
- Scene lookbook, workflow timeline, testimonials, pricing table, FAQ accordion, and booking CTA.
- Modern styling with Tailwind CSS, glassmorphism, gradient backdrops, and responsive layout.

## 🚀 Tech Stack

- [Next.js 14](https://nextjs.org/) with the App Router
- [React 18](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/) + `@tailwindcss/forms`
- [Lucide Icons](https://lucide.dev/)

## 🧱 Project Structure

```
src/
├─ app/
│  ├─ globals.css       // Tailwind setup and theme styles
│  ├─ layout.tsx        // Root layout and metadata
│  └─ page.tsx          // Landing page composition
└─ components/          // Reusable UI sections and widgets
```

## ▶️ Getting Started

```bash
npm install
npm run dev
```

Visit `http://localhost:3000` to explore the site.

## 🧪 Available Scripts

- `npm run dev` – Start the development server
- `npm run lint` – Lint the codebase with Next.js defaults
- `npm run build` – Create a production build
- `npm start` – Launch the production server
